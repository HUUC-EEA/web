## 二、设计语言

整体设计语言：**Retro-Futuristic Terminal Aesthetics（复古未来主义终端美学 / CRT 终端极客风）**，
并融合以下两个分支的气质：

1. **ASCII Brutalism（ASCII 字符粗野主义）**
   - 摒弃商业装饰图片，直接暴露计算机最本质的原料：等宽字体网格、ASCII 字符画、`0/1` 二进制数据流与十六进制坐标
   - Hero 主体为 ASCII 星环行星与 `HUUC-EAA` 字符标题，串口引导行（`UART0_INIT: 115200 8N1`）以打字机动画逐字点亮
2. **Cyber-Schematic Minimalism（赛博原理图极简风）**
   - 融合示波器方波、总线信号（`TX ▲ / RX ▼`）与电路原理图分割线的极简克制表达
   - 左右两侧为持续流动的二进制数据流 Canvas，页面滚动时短暂加速冲刺（14x）后回到常态
3. **CRT 质感**
   - 全站覆盖微弱扫描线（3px 间隔）与暗角滤镜层（`.crt-overlay`）
   - 文字带磷光荧光 `text-shadow`，标题呈现 P31 磷光绿辉光

**克制原则**：文字附近不堆砌装饰性代码符号（如成对的 `[ ]` 括号、`SYS_MEM://` 内存标签、`>_ SYS_MSG` 前缀均已移除），
代码感仅保留在动画、ASCII 艺术与状态栏等"机器本体"层面，保证中文内容的可读性。

**交互与动效**：

- 全屏区块式布局：每个区块占满一屏（`scroll-snap-type: y mandatory`），滚动时内容向上淡出并模糊，松手后自动吸附
- Hero 首屏：串口引导行 → ASCII 行星 → 主标题 → 原理图分割线 → 中文副标题，分五阶段打字机序列
- 鼠标电磁探针：ASCII 字符节点在鼠标靠近时产生偏移、高亮与乱码闪变（`GLITCH_CHARS`）
- 鼠标视差：行星层 / 标题层随鼠标平滑位移（深度不同）
- 终端光标 `█` 以 0.9s 步进闪烁；`prefers-reduced-motion` 下全部动画降级
- 交互动画统一使用缓动曲线 `cubic-bezier(0.16, 1, 0.3, 1)` / `cubic-bezier(0.22, 1, 0.36, 1)`
- 顶部导航栏下滑隐藏、上滑显示

**页面结构**：顶部极客导航栏（状态指示灯 + HUUCEEA 徽章 + 编号菜单 01. 首页 + `+ 加入我们` CTA）
→ Hero 终端首屏 → 加入我们（终端指令 CTA）→ HUD 状态栏页脚。

| 色彩 | 色值 | 用途 |
| --- | --- | --- |
| CRT 深黑底 | `#050706` | 页面全局背景、导航栏底色 |
| P31 磷光绿 | `#38EF7D` | 主强调色：链接悬停、CTA 按钮、ASCII 高亮、左侧 TX 数据流、状态指示灯 |
| 示波器青 | `#00F5D4` | 次强调色：右侧 RX 数据流、DRC/SYNC/STATUS 等校验通过状态、探针近距高亮 |
| 中性灰 | `#D4D4D4` / `#9CA3AF` / `#525252` | 正文 / 次要文字 / 静默标注（Tailwind neutral 系列） |
| 卡片底色 | `rgba(8, 13, 10, 0.78)` | 规格卡片半透明深色底 + 绿色描边（22%–58% 透明度随悬停变化） |

强调色辉光：`text-shadow: 0 0 8px rgba(56, 239, 125, 0.55)`；按钮悬停时辉光增强至 `0 0 22px` 并反色为深底绿字。

## 四、字体规范

- 等宽主字体：JetBrains Mono Variable（100–800）—— 全站默认字体，承载 ASCII 艺术与英文标注
- 中文辅助：Noto Sans SC Variable（100–900）—— 中文正文段落使用 `.font-cn`，在等宽网格中保持可读性
- 像素字体：融合像素 Fusion Pixel 12px（SIL OFL 1.1，中英同风格）—— 导航栏品牌名、菜单项与 CTA 使用 `.font-pixel`
  - 中文字形按站点实际用字裁剪为 15KB 子集，存于 `public/fonts/`；文案变动后运行 `npm run fonts:subset` 重新生成
  - 该字体以 12px 点阵绘制，字号只取 12px 或 24px 才保持像素锐利，`.font-pixel` 元素统一 `text-xs` + `tracking-[1px]`（整数字距）
  - 备选英文像素字体已本地化，改 `.font-pixel` 的类名即可对比：`.font-pixel-arcade`（Press Start 2P，街机）、`.font-pixel-dot`（Silkscreen，点阵）、`.font-pixel-crt`（VT323，终端）；另有 `.font-pixel-mono`（融合像素等宽变体）
- 字体全部本地自托管，不使用 `next/font/google`：外网字体服务不可达时 next/font 会静默退化为比例字体，导致 ASCII 字符画错位
