## 二、设计语言

整体设计语言：**简洁、高级、优雅**。

- 白色为主的纯净画布，保持信息高对比度
- 不使用复杂的光晕、粒子等 AI 感特效
- 卡片采用克制的柔和阴影与细边框，悬停时轻微上浮
- 交互动画统一使用缓动曲线 `cubic-bezier(0.16, 1, 0.3, 1)`，时长 300–500ms
- 全屏区块式布局：每个区块占满一屏，滚动时内容向上淡出并模糊，松手后自动吸附到下一区块
- 页面结构：顶部毛玻璃导航栏（下滑隐藏、上滑显示）→ Hero → 关于我们 → 社团项目 → 加入我们 → 深海蓝页脚

## 三、配色规范

| 色彩 | 色值 | 用途 |
| --- | --- | --- |
| 学院深海蓝 | `#163A7A` | 导航栏按钮、页脚背景、主按钮、CTA 横幅 |
| 极客长春花紫 | `#9A9BE3` | Hero 大标题渐变起始色、次级按钮 |
| 青蓝几何色块 | `#1A809D` | 链接悬停态、强调色、Hero 渐变中段 |
| 浅灰蓝胶囊底色 | `#D3DCE3` | 标签底色、徽章、卡片边框、区块分隔背景 |
| 深钢蓝文字色 | `#1F3B68` | 浅色背景下的标题与正文文字 |
| 纯净白底色 | `#FFFFFF` | 页面全局主背景 |

Hero 大标题渐变：`#9A9BE3 → #1A809D → #163A7A`（紫 → 青蓝 → 深海蓝）。

## 四、字体规范

- 中文 / 主字体：Noto Sans SC（300–700 字重）
- 代码 / 等宽标注：JetBrains Mono（400 / 500），用于英文副标题、区块路径标注（如 `/about`）

## 五、Logo

- 完整版（含文字：`public/logo-full.jpg`）——用于页脚，展示时做圆角处理
