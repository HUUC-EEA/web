## 二、设计语言

整体设计语言：**Retro-Futuristic Terminal Aesthetics（复古未来主义终端美学 / CRT 终端极客风）**，
并融合以下两个分支的气质：

1. **ASCII Brutalism（ASCII 字符粗野主义）**
   - 摒弃商业装饰图片，直接暴露计算机最本质的原料：等宽字体网格、ASCII 字符画、`0/1` 二进制数据流与十六进制坐标
   - Hero 主体为 ASCII 星环行星与 `HUUC-EAA` 字符标题，串口引导行（`UART0_INIT: 115200 8N1`）以打字机动画逐字点亮
2. **Cyber-Schematic Minimalism（赛博原理图极简风）**
   - 融合示波器方波、总线信号（`TX ▲ / RX ▼`）与电路原理图分割线的极简克制表达
   - 二进制数据流：桌面端为左右两栏（`≥768px`，TX 向上 / RX 向下），移动端改为上下两条横带（各 68px 高），填满小屏顶底留白；左右/上下用横向或纵向渐隐遮罩收边
   - 数据流按所在区块切换状态：Hero、关于我们、加入我们正常流动；系统配置（neofetch）整块让位隐藏；社团仓库压暗至 25% 并模糊 3px，避免干扰链接阅读；页面滚动时短暂加速冲刺（14x）后回到常态
3. **CRT 质感**
   - 全站覆盖微弱扫描线（3px 间隔）与暗角滤镜层（`.crt-overlay`）
   - 文字带磷光荧光 `text-shadow`，标题呈现 P31 磷光绿辉光

**克制原则**：文字附近不堆砌装饰性代码符号（如成对的 `[ ]` 括号、`SYS_MEM://` 内存标签、`>_ SYS_MSG` 前缀均已移除），
代码感仅保留在动画、ASCII 艺术与状态栏等"机器本体"层面，保证中文内容的可读性。

**交互与动效**：

- 全屏区块式布局：每个区块占满一屏（`scroll-snap-type: y mandatory`），滚动时内容向上淡出并模糊，松手后自动吸附
- Hero 首屏：串口引导行 → ASCII 行星 → 主标题 → 原理图分割线 → 中文副标题，分五阶段打字机序列
- 鼠标电磁探针：ASCII 字符节点在鼠标靠近时产生偏移、高亮与乱码闪变（`GLITCH_CHARS`）
- 鼠标视差：行星层 / 标题层随鼠标平滑位移（深度不同）
- 终端光标 `█` 以 0.9s 步进闪烁；`prefers-reduced-motion` 下全部动画降级
- 交互动画统一使用缓动曲线 `cubic-bezier(0.16, 1, 0.3, 1)` / `cubic-bezier(0.22, 1, 0.36, 1)`
- 顶部导航栏下滑隐藏、上滑显示

**页面结构**：顶部极客导航栏（`HUUCEEA` 蓝色徽章 + 品牌名「电子爱好者协会」+ 编号菜单 `01. 首页 / 02. 关于我们 / 03. 社团仓库` + `+ 加入我们` CTA）
→ Hero 终端首屏 → 系统配置（仿 Konsole neofetch）→ 关于我们（PCB 蚀刻板 + 协会简介）→ 社团仓库（GitHub 三入口）→ 加入我们（终端指令 CTA）→ HUD 状态栏页脚。

导航栏尺寸：高度 56px（<640px）/ 64px（≥640px），左右内边距 16px / 24px，菜单项间距 20px（≥1280px 为 28px）。
品牌行改为「徽章在前、社团名在后」，并去掉冗长的校名前缀（`河南城建学院` 只保留在页脚与 neofetch 信息里），
桌面端整条导航实测只需约 712px，1024px 断点也能完整展开、不再需要收起徽章。
字号：品牌名 20px、徽章与菜单项/CTA 16px（<640px 时菜单降为 12px），形成「品牌略大、菜单中等」的层级。

## 四、字体规范

- 等宽主字体：JetBrains Mono Variable（100–800）—— 全站默认字体，承载 ASCII 艺术与英文标注
- 中文辅助：Noto Sans SC Variable（100–900）—— 中文正文段落使用 `.font-cn`，在等宽网格中保持可读性
- 中文标题：得意黑 Smiley Sans Oblique（SIL OFL 1.1，`@chinese-fonts/dyh`）—— `.font-display`，用于 Hero 副标题「电子爱好者协会」与各区块中文标题；窄斜黑体自带速度感，比 Noto 粗体更「极客海报」，且只有单一字重、不会让层级变复杂
- 英文标注：Share Tech Mono（`@fontsource/share-tech-mono`，仅拉丁，约 15KB）—— `.font-tech`，用于 `ABOUT_US` / `REPOSITORY` / `$ ./join` 这类终端小标签，比 JetBrains Mono 更细瘦、更有仪器面板味
- 像素字体：融合像素 Fusion Pixel 12px（SIL OFL 1.1，中英同风格）—— 导航栏品牌名、菜单项与 CTA 使用 `.font-pixel`
  - 中文字形按站点实际用字裁剪为约 20KB 子集，存于 `public/fonts/`；文案变动后运行 `npm run fonts:subset` 重新生成
  - 该字体以 12px 点阵绘制，12px / 24px 是最锐利的两档；导航栏当前取「品牌名 20px、徽章与菜单项 16px」的中间档，
    边缘会有轻微抗锯齿柔化（比 24px 克制、比 12px 易读），字距取整像素（`tracking-[1px]`）
  - 备选英文像素字体已本地化，改 `.font-pixel` 的类名即可对比：`.font-pixel-arcade`（Press Start 2P，街机）、`.font-pixel-dot`（Silkscreen，点阵）、`.font-pixel-crt`（VT323，终端）；另有 `.font-pixel-mono`（融合像素等宽变体）
- 得意黑在 npm 上是 cn-font-split 切好的 59 个 `unicode-range` 分片，直接引入会下载约 940KB；`npm run fonts:subset` 会按站点用字重新裁剪，只保留用到的分片（当前 24 个、约 93KB）并生成 `app/fonts/smiley-sans.css`，分片文件在 `public/fonts/smiley/`
- 字体全部本地自托管，不使用 `next/font/google`：外网字体服务不可达时 next/font 会静默退化为比例字体，导致 ASCII 字符画错位

**字体分工**（克制原则：全站只用四种面孔）
等宽 JetBrains Mono 打底 → 中文正文 Noto Sans SC → 中文标题得意黑 → 像素字体只做导航栏 → Share Tech Mono 只做英文小标签。

## 八、加载优化（2026-10-17）

- **区块加载隔离**：neofetch 区块经 `DeferredMount` 拆为独立 chunk，首屏 HTML/JS 不含它；滚动到距视口 1.6 屏内才下载挂载，占位为等高的 Konsole 窗口骨架，避免吸附跳动
- **运行时隔离**：`HeroTerminal` 滚离首屏（>1.2 屏）后停掉整条 rAF 探针循环，滚回时恢复；`TerminalBackdrop` 改在 `requestIdleCallback`（兜底 300ms）空闲初始化，不与首屏渲染争主线程
- **字体瘦身**：移除从未使用的 Press Start 2P / Silkscreen / VT323 三个 @fontsource 导入与对应 CSS 类；为首屏像素字体子集加 `<link rel="preload">`，消除 swap 闪烁
- **实测结果**：首屏 JS 原始体积 624,949 B → 601,551 B（−3.7%），其中 neofetch chunk 10.4KB 与其共享 chunk 14.1KB 改为按需加载；CSS 144,618 B → 140,759 B；生产环境首屏传输 JS 148.6KB / CSS 43.2KB / 8 个 JS 请求，控制台零告警
